TapShare

Tap two phones together to send a file.

TapShare pairs Android phones over NFC and moves the file across a private Wi-Fi link. Nothing is uploaded and there is no account. When the phones can't touch, a six-character code does the pairing from any browser.

Two ways to pair

Use the tap when both phones are Android and next to each other. Use a code for everything else.

Tap

Android app with Android app

Hold the phones back to back. NFC passes a one-time key, and Wi-Fi Direct carries the file. It needs no internet and runs at Wi-Fi speed.

Both phones need NFC with card emulation and Android 10 or newer.

Code

Any device with any device

Open the web version, or the app's Web mode, and get a six-character code. Type it on the other device and the two connect directly. It works on iPhone, Windows, Mac, Linux and Android.

Needs a modern browser and an internet connection to pair.

What happens when you tap

Nothing travels farther than a few centimetres until both phones are already talking.

  1. The receiver opens Receive.Its phone starts a private Wi-Fi Direct network with a random name and password, then offers those details over NFC like a contactless card.
  2. The sender picks a file and taps.The sender's phone reads the network details from the NFC tap. They only work for this one transfer.
  3. The phones connect directly.The sender joins the private network and streams the file to the receiver, with a one-time token that proves it was the phone that tapped.
  4. The file lands in Downloads.It is saved in Downloads/TapShare and the private network disappears.

What happens with a code

The same idea without the touch. A short code replaces the NFC tap.

  1. The receiver gets a code.Open Receive on the website, or in the app's Web mode. A six-character code and a QR code appear.
  2. The sender enters it.Type the code, or scan the QR code with a phone camera. That opens the web version with the code already filled in.
  3. The browsers connect directly.A public pairing service introduces the two devices. The file itself never passes through it.
  4. The receiver accepts.Nothing is saved until the receiver chooses Accept.

Who can talk to whom

Browsers can't act as an NFC card or create a Wi-Fi Direct network, so a tap never pairs with the website. Use a code for that.

Privacy and security

TapShare has no server of its own and no accounts.

  • No one stores your file.Tap transfers never touch the internet. Code transfers go from device to device.
  • Tap uses a private network.The Wi-Fi Direct network is protected with WPA2 and a random password made for that one transfer, and only the phone that tapped holds the one-time token. The file is not encrypted again on top of the Wi-Fi link.
  • Code connections are encrypted.Browsers encrypt the connection end to end with WebRTC. The pairing service sees the code and the network addresses needed to connect, never the file. If a direct path is blocked, the encrypted traffic can be relayed.
  • The receiver decides.In the web version, every incoming file waits for Accept or Decline before anything is saved.

Questions

Does it work on iPhone?

Yes, through the web version in Safari. The tap itself is Android only, because iPhone apps can't act as an NFC card or create a Wi-Fi Direct network.

The tap did nothing. What should I check?

NFC must be on for both phones, with the screens on and unlocked. The receiving phone should say it is ready. Hold the phones back to back for a second or two, with the NFC antenna of one over the other. The antenna is usually near the camera.

Why does a code need internet?

The two devices have to find each other first. Only that short introduction goes through the pairing service.

How big can a file be?

The sender reads the file in pieces, so size is not a limit there. A receiving browser tab holds the file in memory until it is complete, so a very large file may not fit. The Android app saves to storage as the data arrives.

How do I get the Android app?

The GitHub repository builds an APK automatically. Open the latest releases and download the listed file.

Can I run my own pairing service?

Yes. The web version reads web/config.js. Point it at your own PeerJS server and nothing else changes.

Is it related to Quick Share or AirDrop?

No. TapShare is an independent open source project.
